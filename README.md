# ARTCAMINHO — сайт по макету Figma

## Как смотреть локально

    python dev_server.py

и зайти на http://localhost:5190. Dev-сервер имитирует `send.php`: заявки с форм печатаются
в консоль, письма не отправляются.

## Как править
Готовые `.html` в корне **собираются** из `src/`. Править нужно исходники, потом выполнить:

    python build.py

- `src/pages/` — страницы (index, catalog, product, courses, gallery, mosaic, contacts, favorites)
- `src/partials/` — общие блоки: шапка, меню, подвал, карточка товара, фильтр, форма, корзина, модалки
- `css/style.css` — все стили, адаптив внизу файла (1280 / 1100 / 700px)
- `js/main.js` — корзина, избранное (localStorage), формы, модалки, аккордеоны, фильтр, мобильное меню
- `assets/icons/` — иконки из макета (SVG), собираются в спрайт автоматически
- `assets/img/` — оптимизированные картинки из макета
- `assets/fonts/` — шрифт Actay (проверьте лицензию для коммерческого использования)

## Формы → письмо магазину
Покупка только по телефону: во всех формах (Есть вопросы?, Контакты, заказ из корзины) клиент оставляет
номер, форма уходит в `send.php`, он присылает письмо на служебную почту магазина (на сайте её нет).

1. В начале `send.php` укажите:
   - `MAIL_TO` — куда приходят заявки;
   - `SHOP_PHONE` — телефон магазина (показывается клиенту, если отправка не удалась);
   - `MAIL_FROM` — адрес **на домене сайта** (например `noreply@ваш-домен.ru`), иначе письма уйдут в спам.
2. Нужен хостинг с PHP 7.4+ (Beget, Timeweb, REG.RU и т.п. — есть по умолчанию).
3. После загрузки на хостинг отправьте тестовую заявку и проверьте папку «Спам».

В письме: название формы, телефон клиента, страница, а для корзины — список товаров и сумма.
Защита: скрытое поле-ловушка для ботов и не чаще 1 заявки в 20 секунд с одного IP.

На хостинг загружать: всё, **кроме** `src/`, `build.py`, `dev_server.py`, `README.md`.

## Карта
На странице «Курсы» — Яндекс.Карта (`src/pages/courses.html`). Сейчас метка в центре Тольятти.
Чтобы сменить место: в адресе iframe замените координаты в `ll=` и `pt=` (долгота,широта),
затем `python build.py`. Подпись на карте — там же, в `map-card__label`.

## Телефон магазина
Сейчас везде стоит `+7 900 000-00-00`. Заменить во всех файлах `src/` (поиск по `79000000000` и `900 000-00-00`)
и в `send.php`, затем `python build.py`.

## Юридические страницы
`privacy.html` (политика конфиденциальности), `cookies.html`, `terms.html` (условия покупки).
Места, которые нужно заполнить (ИП/ООО, ИНН, ОГРН, адрес, дата), подсвечены розовым — в исходниках это
`<mark class="fill">`. Тексты — шаблон; перед запуском лучше показать юристу.
Уведомление о cookie показывается один раз и запоминает согласие в браузере.
